# Machine Learning Car Price Prediction

This project was completed as part of my machine learning coursework. The goal was to use machine learning to predict used car prices based on different vehicle characteristics.

The project was developed in Python using JupyterLab and explores how different factors can influence the price of a used vehicle.

## About the Project

The project uses a dataset containing information about used cars to train and evaluate a machine learning model for price prediction.

The main parts of the project involve:

- Exploring the dataset and identifying factors that affect vehicle prices
- Preparing the data for machine learning
- Training a regression model to predict car prices
- Evaluating the model's predictions and performance

A more detailed explanation of the process and results can be found in the project report included in this repository.

## Tools Used

- Python
- JupyterLab
- Anaconda
- Machine Learning (Regression)

## Files

- `Machine Learning Project.ipynb` — Jupyter Notebook containing the code and analysis
- `used_car_price_dataset_extended.csv` — Dataset used for training and testing
- `Predicting Used Car Prices With Machine Learning.pdf` — Project report explaining the methodology and results

## How to Run

1. Clone or download the repository.
2. Open Anaconda Navigator and launch JupyterLab.
3. Navigate to the project folder and open `Machine Learning Project.ipynb`.
4. Make sure the necessary Python libraries are installed.
5. Run the notebook cells in order.

The dataset is already included in the repository.
